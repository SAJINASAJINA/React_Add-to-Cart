# Add to Cart App

A responsive shopping cart application built using React.js, React Router, Tailwind CSS, and the Fake Store API.

## Features

- Fetches products from the Fake Store API.
- Displays product images, titles, descriptions, and prices.
- Responsive product listing.
- Add and remove products from the cart.
- Increase or decrease product quantities.
- Displays individual item totals and cart total.
- Automatically applies a 10% discount.
- Displays the final discounted price.
- Navigation between Products and Cart pages using React Router.

## Technologies Used

- React.js
- JavaScript
- React Router DOM
- Tailwind CSS
- HTML
- Fake Store API
- Vite

## Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd add-to-cart-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
